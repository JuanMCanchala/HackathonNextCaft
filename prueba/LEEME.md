# Vídeos de prueba

Clips verificados de punta a punta contra el sistema real. Se pueden subir
desde **Monitor en vivo → analizar tu propio vídeo** sin miedo a que no
disparen delante de nadie.

## pelea_corta.mp4

| | |
|---|---|
| Duración | 3.5 s (105 fotogramas) |
| Tamaño | 1.0 MB |
| Tiempo de análisis | **9.5 s** de punta a punta |
| Resultado | 2 disparos del filtro, **2 confirmados** como agresión física |
| Efecto | Abre incidente en Convex y **envía el correo de aviso** |

Es un recorte de `data/demo/violence/demo_02.mp4` centrado en la acción. El
original dura 5.7 s y tarda **36 s** en analizarse: casi todo el tiempo se va
en las verificaciones con el modelo de visión, no en el filtro geométrico, así
que quitar segundos muertos del principio y del final baja el tiempo a menos
de un tercio sin perder el incidente.

## Para la demo

Sube este. Diez segundos de espera con la barra de progreso moviéndose se
sostienen delante de un jurado; un vídeo de dos minutos serían doce minutos de
análisis y no hay forma de rellenar ese silencio.

Si quieres enseñar el caso completo con más contexto de antes y después, usa
los botones de escena preparada (`demo_01`, `demo_02`), que son los mismos
clips sin recortar.
